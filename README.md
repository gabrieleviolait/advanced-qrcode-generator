# Advanced QRCode Generator

A free, privacy-friendly web tool to generate customizable QR codes directly in the browser.

## Features

- Generate QR codes for URLs, text and other supported content types
- Customize foreground and background colors
- Set error correction level
- Download the generated QR code as PNG
- Runs directly in the browser
- No account required
- No server-side storage

## Privacy

This tool generates QR codes locally in the user's browser.

The values entered by the user are not intentionally sent to external QR generation services, stored on a server, or logged by this project.
